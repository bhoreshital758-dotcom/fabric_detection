# Fabric AI Detection – Eco-Friendly or Not?

Upload or capture a fabric photo. The app identifies the fabric (cotton, linen, nylon, polyester, silk, wool)
using a MobileNetV2 transfer-learning model and shows whether it is eco-friendly.
